Cache Viewer & Editor

Browse the metadata extract like a spreadsheet — click a column header to sort (drag its edge to resize), filter per column, or search across everything. It works like Excel: click a cell and just type to replace its value (double-click or F2 edits in place), arrow keys move, Enter saves and moves down, Tab saves and moves right, Esc cancels; ✕ deletes a row. Shift+↓/↑ (or shift-click) selects a column range — then ⌘/Ctrl-D fills the top value down, Enter types one value into every selected row, and ⌘/Ctrl-V pastes a block copied from Excel (rows × columns, anchored at the selection). Album-level fields (album title/artist, label, ℗/© lines, dates, catalogue, barcode, language) save to every track of the album — bulk edits touching several albums ask first. Saves land in the cache immediately and queue up on the ⇪ Push changes to databases button — click it when you're done editing to review old → new per matched record and push to Gallo Catalogue, CMS 2024 and MadStreamer in one go. For bulk corrections: ⬇ Download xlsx → edit in Excel → ⬆ Replace from xlsx (a timestamped S3 backup is written before every replace). Edits persist to the shared S3 copy, so they survive deploys and both local and hosted GalloIngest see the same catalogue.

Sync from Ingrooves Export

The client edits metadata in the Ingrooves/Virgin portal; download the catalogue export (one row per track) and upload it here — multiple files at once is fine, the portal caps each export at 10,000 rows. Rows are matched to the cache by ISRC (then UPC + track #) and only cells that actually differ are proposed. Applying writes the ticked rows to the cache and queues them on ⇪ Push changes to databases.
